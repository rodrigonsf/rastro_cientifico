# Download do Rastro Científico

**Versão homologada: 0.4.2 | Edição CNPq**

## Baixar

Acesse a página oficial de Releases do projeto:

**[Baixar o Rastro Científico 0.4.2](https://github.com/rodrigonsf/rastro_cientifico/releases/tag/v0.4.2)**

Na página da versão, consulte os arquivos e as instruções disponibilizados pelo projeto.

## Como executar

1. Baixe o pacote ZIP da versão 0.4.2.
2. Extraia o conteúdo do arquivo.
3. Abra o arquivo `index.html` no Google Chrome ou Microsoft Edge.
4. A aplicação será executada localmente no navegador. Não é necessário instalar Node.js, npm, servidor ou realizar compilação.

## Armazenamento dos dados

Os dados cadastrados ficam armazenados localmente no navegador, por meio do IndexedDB. Não há conta de usuário, sincronização em nuvem ou envio automático dos registros para um servidor.

Para transferir os dados entre computadores ou navegadores, utilize as funções de exportação e restauração de backup em JSON disponíveis na aplicação.

**Atenção:** o armazenamento local não equivale a criptografia. Proteja o dispositivo e os arquivos de backup. Evite inserir dados pessoais, sensíveis, sigilosos ou confidenciais desnecessários.

## Métricas de download

Para que o GitHub contabilize downloads do pacote como ativo de uma Release, o arquivo ZIP precisa estar anexado à seção **Assets** da Release. Um link inserido no texto de descrição da Release não equivale a um ativo anexado.
