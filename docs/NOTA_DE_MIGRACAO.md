# Nota de migração documental

Este repositório foi organizado em torno da versão 0.4.2 da Edição CNPq.

## Conteúdo incorporado
- Orientações de contribuição, revisadas para o núcleo atual e para as duas edições previstas.
- Aviso de escopo, responsabilidades e limites da plataforma.
- Inventário normativo preliminar, sujeito à conferência em fontes oficiais.
- Documentação da plataforma e manuais correspondentes à versão 0.4.2.
- Documentação técnica vinculada ao arquivo `index.html`.

## Conteúdo legado não incorporado
- README experimental 0.2.0: descrevia gravação em pasta via File System Access API, estrutura `Rastro/`, diário metodológico, fontes, inventário de materiais e checklist, incompatíveis com a versão 0.4.2.
- Gabarito operacional em PDF: instruções destinadas ao comportamento de um assistente, sem função como documentação do produto.
- Funcionalidades e fluxos exclusivos da versão abandonada: não foram transportados para o produto atual.

## Cuidados
O inventário normativo é um ponto de partida documental, não uma validação jurídica. Antes de transformar qualquer item em regra de software, confira o texto oficial, o âmbito de aplicação e o dispositivo específico.
