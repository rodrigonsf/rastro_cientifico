# rastro_cientifico
Ferramenta para documentar, organizar e gerar declarações sobre o uso de Inteligência Artificial Generativa (IAG) e Inteligência Artificial Preditiva (IAP) em pesquisas científicas, com edição dedicada às diretrizes do CNPq. Promove transparência metodológica, rastreabilidade e responsabilidade no uso de IA na pesquisa.
